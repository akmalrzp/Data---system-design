# 1. Module types

Modules are classified per entity by their relationship to the data: owner, consumer using data as attributes, consumer using data as an index. A real module is usually several at once ([hybrid-module](../modules/hybrid-module.md)). This section also gives measurements for scoping modules and a test for placing features, then lists special cases.

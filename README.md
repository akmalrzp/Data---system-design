## What is in the folder

- System design guide.md is the whole guide in one file, about 1,100 lines, with a table of contents. It is generated from the pages, so edit the pages, not this file
- wiki/ holds the atomic pages, plus index.md, log.md and SCHEMA.md. The page folders are sources, guide, concepts, modules, tables, patterns, decisions, usecases and ops.
- raw/ holds copies of your two source files and a record of your answers in this chat.
- scripts/build_guide.py regenerates the index and the single-file guide after you edit pages.

## Things to check before relying on it

Pages tagged proposal are my suggestions, not from your sources. This includes the module scope criteria, the feature placement test, and the accountability default. Erasure law (UU PDP, GDPR) was not researched, so confirm it with legal.
